## 🚀 Featured Projects

### 1. Virtual RF Test Bench

[![GitHub](https://img.shields.io/badge/GitHub-Virtual_RF_Test_Bench-black?style=flat&logo=github)](https://github.com/kaustubhagarwal18/virtual-rf-testbench)

A software-simulated RF testing environment designed to demonstrate automated testing, CI/CD, container security, and observability.

- Simulated SCPI-based RF instruments.
- Built automated regression tests with injected fault scenarios.
- Implemented Docker-based deployment with security hardening.
- Integrated GitHub Actions, Trivy, and SBOM generation.
- Developed a FastAPI service with persistent test history.
- Added Prometheus/Grafana monitoring and a Kubernetes Helm chart.
- Experimented with a local RAG-based troubleshooting assistant.

**Technologies:** Python, FastAPI, Docker, GitHub Actions, Trivy, Kubernetes, Helm, Prometheus, Grafana, Ollama.

### 2. Local Fleet CI/CD Pipeline

[![GitHub](https://img.shields.io/badge/GitHub-Local_Fleet_CI%2FCD-black?style=flat&logo=github)](https://github.com/kaustubhagarwal18/local_fleet_cicd)

An infrastructure automation project demonstrating end-to-end provisioning, configuration management, software builds, and deployment across a local virtual machine fleet.

- Provisioned virtual machines using Terraform and Multipass.
- Automated configuration and deployment using Ansible.
- Built and deployed llama.cpp with GGUF models.
- Implemented health checks, rolling updates, and automatic rollback.
- Added automated validation using GitHub Actions and local workflow execution.
- Integrated Prometheus and Grafana for service monitoring.

**Technologies:** Terraform, Ansible, Python, Docker, GitHub Actions, Prometheus, Grafana, llama.cpp.
